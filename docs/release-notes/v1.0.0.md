First release of Word Solver.

- **Guess Helper** for five-letter guessing games: type your guesses, tap tiles to set gray, yellow or green, see every word that still fits and the best next guess by information (bits), weighted by how common each word is. Repeated letters are handled like the real game.
- **Word Finder**: your letters plus blanks (?), starts with, ends with, contains and length filters, results grouped by length with tile points.
- Lessons and an app tour with live examples, four looks in light and dark, works offline, on the web, as an installed app, and on Windows.
- Words: ENABLE (public domain). Word frequencies: wordfreq (CC BY-SA 4.0).
